## Админка

Вход: `admin.html`, пароль владельца. В коде только хеш PBKDF2-HMAC-SHA256 (60 000 итераций,
случайная соль), открытого пароля нет — см. `assets/js/admin-auth.js`. Смена пароля — раздел «Доступ».
После 5 неверных попыток вход блокируется на минуту.
Разделы: Обзор, Заказы, Заказы с сайта, Товары, Урны, Синхронизация, Обращения, Архив, Доступ.
Данные в `localStorage`: `smartbin_product_overrides_v1`, `smartbin_orders_v1`,
`smartbin_order_status_v1`, `smartbin_bins_v1`, `smartbin_sync_v1`, `smartbin_archive_v1`,
`smartbin_admin_auth_v1` (свой пароль).

## Синхронизация и канал

- `data/store.json` — цены, заказы, урны. Чтение через GitHub API (свежие данные),
  запасной путь `raw.githubusercontent.com` (кэш до 5 минут). Запись — по токену
  (Contents: read/write), хранится только в браузере.
- `data/chat.json` — адрес приёмника: Apps Script `/exec` (уже вписан).
- Приёмник: `docs/apps-script-chat.gs`, хранит в Google Таблице два листа —
  `chat` и `orders`. Действия: `list`, `orders`, `send`, `reply`, `order`, `orderStatus`.
- Пока развёрнут старый скрипт, заказ уходит сообщением и виден с пометкой «из чата».

## Ограничение по размеру мусора

Жёлоб 220 × 90 × 34 и камера 140 × 160 × 150 пропускают только мелкий мусор:
ширина предмета до **90 мм** и высота до **30 мм** (по стенке жёлоба).
Не проходит: бутылка 1,5 л не смятая (Ø100), коробка от пиццы, обувная коробка.
Проходит: смятая бутылка, банка, стакан, бумага, упаковка.
