Общие данные для всех устройств

не настроено

Панель хранит данные в файле data/store.json этого репозитория. Чтение открытое — витрина подхватывает цены сама на любом устройстве. Для записи нужен fine-grained токен с правом Contents: Read and write на этот репозиторий.

Хранится только в этом браузере. Создайте fine-grained токен на один репозиторий со сроком 30 дней.

«Загрузить» перезапишет локальные данные содержимым файла. В публичном репозитории заказы видны всем — не вводите реальные телефоны и адреса.

Пароль панели

встроенный пароль

Пароль хранится только как хеш PBKDF2-HMAC-SHA256: встроенный — константой в assets/js/admin-auth.js, свой — в этом браузере. Открытого пароля нет ни на странице, ни в коде.

Свой пароль действует только в этом браузере; на другом устройстве работает встроенный. Сессия живёт до закрытия вкладки, после 5 неверных попыток вход блокируется на минуту.
