# SmartBin — умная мусорка с автоматической сортировкой

Одностраничный лендинг-магазин умных урн SmartBin: витрина моделей, магазин запчастей,
корзина с оформлением заказа, опрос о сценариях использования и окно поддержки.

Проект целиком помещается в один файл — сборка, npm-зависимости и сервер не нужны.

## Возможности

- **Блок «Как это работает»** — три шага работы умной урны с иконками.
- **Витрина моделей** — SmartBin Eco (40 л) и SmartBin Pro (80 л) с характеристиками и ценами.
- **Магазин запчастей** — сервопривод лотка, комплект мешков, Wi-Fi/Bluetooth-модуль.
- **Корзина** — модальное окно: добавление товара, изменение количества, удаление,
  подсчёт итоговой суммы, счётчик в шапке.
- **Опрос** — выбор среды использования (офис, кафе, производство, дом);
  открывается автоматически через 15 секунд, но не чаще одного раза за сессию.
- **Чат поддержки** — плавающая кнопка и ссылка в подвале, отправка сообщений по Enter,
  имитация ответа оператора.
- **Анимации** — секции плавно появляются при прокрутке (IntersectionObserver),
  логотип собран из инлайнового SVG.
- **Адаптивная вёрстка** — сетки и модальные окна подстраиваются под мобильные экраны,
  плавная прокрутка по якорным ссылкам, «липкая» шапка, блокировка прокрутки под оверлеями.

## Запуск

Откройте `index.html` в браузере — этого достаточно.

При необходимости поднимите локальный сервер:

```bash
python -m http.server 8000
# затем http://localhost:8000
```

## Технологии

- HTML5, CSS3 (переменные, grid, flexbox, media queries)
- Чистый JavaScript (ES6), без фреймворков и сборщиков
- Внешних зависимостей нет: изображения и иконки встроены в файл

## Структура

```
index.html    # вся страница: разметка, стили, скрипты
README.md     # описание проекта
```

## Публикация на GitHub Pages

1. Settings → Pages.
2. Source: *Deploy from a branch*, ветка `main`, папка `/ (root)`.
3. Через минуту сайт будет доступен по адресу `https://<username>.github.io/<repo>/`.

## Примечания

- Корзина хранится в памяти страницы и очищается при перезагрузке — постоянного
  хранилища и бэкенда пока нет.
- Кнопка «Перейти к оплате» показывает заглушку: платёжный шлюз не подключён.
- Ответы в чате поддержки имитируются на клиенте.
